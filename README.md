A bilingual full-stack website developed for **Al-Yasmin Nursery**, combining a modern customer-facing experience with a complete content management system for the nursery team.

---

##  About the Project

**Al-Yasmin Nursery** is a real-world business website designed to replace static business pages with a dynamic platform that can be managed entirely through an admin dashboard.

The project focuses on:

- Modern and responsive user experience
- Arabic and Hebrew support
- Dynamic content management
- Product and offer management
- Professional image handling
- Secure administration
- Mobile-first design
