# Placeholder Images

This folder holds clearly-labeled development placeholders only —
no real nursery photos. Files expected here in later phases:

- `hero-placeholder.jpg`      — homepage hero background
- `plant-placeholder.jpg`     — used by PlantCard when a plant has no uploaded image yet
- `gallery-placeholder.jpg`   — used by gallery grid items with no image yet

When real photos are ready, they are uploaded through the admin panel
to Cloudinary — they do NOT get committed to this repo. These files
exist only so the UI never shows a broken image during development.
